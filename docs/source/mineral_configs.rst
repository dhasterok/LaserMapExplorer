Mineral Configuration Reference
********************************

Every mineral listed on the :doc:`stoichiometry` page is defined by one YAML config file in ``resources/minerals/``, validated against the schema in ``src/stoichiometry/config.py``. This page shows the full, current content of each file -- see :doc:`stoichiometry_technical` for what the fields mean and how they drive the calculation.
